# BRIGHT-COFFEE-SHOP
# Overview
This project presents a sales analysis of the **Bright Coffee Shop** transactional dataset. The objective of the case study was to analyze sales performance and provide data-driven insights that would help the Chief Executive Officer (CEO) make informed business decisions to improve revenue, identify high-performing products, understand customer purchasing patterns, and optimize operational performance.
The dataset contains transaction-level information including transaction dates and times, product details, quantities sold, store locations, and unit prices. SQL was used to clean, transform, and analyze the data before generating business insights.

# Objectives
The primary objectives of this case study were to:
- Identify the products that generate the highest revenue.
- Determine the busiest trading periods during the day.
- Analyze sales trends across products and time intervals.
- Provide actionable recommendations to improve sales performance.
-Prepare clean and structured data suitable for business reporting and dashboard development.

## Methodology
The project followed a structured data analysis process consisting of data cleaning, transformation, analysis, and interpretation.

### 1. Data Cleaning
The following data quality checks and transformations were performed:
-Checked for missing (NULL) values.
- Verified data types for all columns.
- Converted the **unit_price** column from a string to a decimal format.
- Created a **Total Amount** field by multiplying transaction quantity by unit price.
-Created transaction time buckets to group transactions into meaningful business periods such as Breakfast, Late Morning, Lunch, Afternoon, and Evening.
- Validated the dataset for consistency before analysis.

### 2. Data Analysis
SQL queries were written to analyze:

- Total revenue
- Revenue by product category
-Revenue by product type
-Top-selling products
-Revenue by store location
-Sales by transaction time bucket
-Quantity of products sold
-Monthly sales trends
-Daily sales trends
- Average order value
